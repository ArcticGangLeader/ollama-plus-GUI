# 📖 简介

**Ollama Win32 GUI** 是一款运行在 Windows 平台上的 Ollama 图形化管理工具，使用 Win32 GUI 构建，目标是让本地大模型的管理变得像使用普通桌面软件一样简单

通过它，你不再需要频繁地敲命令行去拉取模型、重命名模型、启动服务端——**点几下鼠标就能完成**。同时，它把「魔搭社区（ModelScope）搜索」和「Ollama 模型管理」打通，找到 GGUF 模型后可以**自动下载并导入**，省去手动下载、写 Modelfile、转换导入的繁琐流程

> ⚠️ **注意**：本项目目前仍在开发中，目前只做了前端后端还是依靠ollama的CLI界面，但是操作啥的确实便携了；这只是我的一个半成品被我提前发布出来而已

# ✨ 功能特性

### 1️ 魔搭搜索 —— 在魔搭社区快速找模型（推荐中国的用户使用）

再也不用在浏览器和终端之间来回切换

| 能力 | 说明 |
| :--- | :--- |
| 🔍 **关键词搜索** | 直接在工具内搜索魔搭（ModelScope）社区的 GGUF 格式模型 |
| 📋 **结果展示** | 列出模型名称、发布者、量化版本、文件大小等信息，方便对比选择 |
| 🎯 **一键下载** | 选定模型与量化版本后，自动下载到本地指定目录 |
| 📥 **自动导入** | 下载完成后自动生成 Modelfile 并导入到 Ollama，可直接使用 |
| 📊 **进度反馈** | 下载与导入过程显示进度与状态，避免"卡死"的错觉 |

> 💡 适用于想快速体验各种开源 GGUF 量化模型的用户，尤其适合网络环境需要走镜像源/代理的场景

> 这个平台的服务器位于中国，所以如果你地理位置不在中国则不推荐使用此功能，会很卡
---

## 2 本地模型 —— 本地 GGUF 全流程管理

对 Ollama 已有模型和本地 GGUF 文件进行集中管理

| 能力 | 说明 |
| :--- | :--- |
| 📃 **模型列表** | 一览本地 Ollama 已安装的所有模型及其大小、修改时间等信息 |
| 🗑️ **删除模型** | 选中模型即可删除，支持二次确认，避免误删 |
| ✏️ **重命名模型** | 无需手动 `copy` + `rm`，图形化完成模型重命名 |
| 📂 **导入本地 GGUF** | 选择本地 `.gguf` 文件，自动生成 Modelfile 并导入 Ollama |
| ▶️ **运行模型** | 一键启动模型进行对话/推理，快速验证模型是否可用 |

> 💡 无论是从魔搭下载的模型，还是你从其他渠道获取的 GGUF 文件，都可以在这里统一管理

---

## 3️ 服务端 —— 一键开启 Ollama API 服务

把 Ollama 当作本地 API 服务对外提供，并加上必要的安全控制

| 能力 | 说明 |
| :--- | :--- |
| 🚀 **一键启停** | 图形化开启 / 关闭 Ollama 服务端，无需命令行操作 |
| 🔌 **自定义端口** | 可设置服务监听端口，避免端口冲突或满足局域网访问需求 |
| 🔑 **API Key 验证** | 开启 API Key 校验，未携带正确 Key 的请求将被拒绝 |
| 🚫 **IP 黑名单** | 将指定 IP 加入黑名单，快速拦截恶意或异常请求 |
| 📈 **状态展示** | 实时显示服务运行状态、当前端口等关键信息 |

> 💡 适合把本地 Ollama 暴露给局域网内其他设备（如手机、平板、其他电脑）使用的场景，配合 API Key 与 IP 黑名单，安全性更有保障
